VoiceForge — blind phenotype labeling

🔒 You see only the raw conversation — no scores, no failure flags, no call id, no source. Label honestly; don't aim for any split. One pass per call, one save.
Level 1 — Outcome. Choose exactly one: success, fail, or unsure. Did the caller ultimately achieve their goal?
Level 2 — Phenotype primitives. Review every group and select all tags that apply. Zero tags is valid only after deliberate review. Positive and negative tags may coexist — a call can succeed with friction or fail despite good handling. Judge each tag independently.
Level 3 — Derived archetypes. Not labeled here. VoiceForge derives these later from your outcome + primitive tags + deterministic signals.
⚠️ This labeling view is transcript-only. Do not infer audio quality, accent, noise, network conditions, or voice naturalness — these are unavailable for nearly all current calls. Do not hand-label latency or overlap; where timestamp data permits, VoiceForge computes those deterministically elsewhere.
